# 慧投小程序

原生微信小程序，包含微信登录、手机号绑定、四个市场的 AI 研究对话、慧投圆桌、跨市场自选、财报解读、账户持仓及价格提醒。

## 布局与适配

- 沿用网页的浅色背景、白色内容块和低饱和绿色，以市场入口和最近研究替代桌面侧栏与宽表格。
- 首页采用两列市场卡片，并提供投资工作台与圆桌入口；对话记录使用紧凑列表，首次发言后才保存历史。
- 投资工作台将网页宽表格改为卡片，支持搜索添加、市场筛选、财报指标与 SEC 来源、AI 解读及重试、账户持仓和提醒邮箱；公司页可设置目标价。
- AI 回答与财报解读使用安全的富文本 Markdown 排版。
- 对话页使用微信原生导航，消息区独立滚动；输入区预留底部安全区，键盘显示时调整页面底部位置。
- 使用弹性布局、内容最大宽度和小屏样式；主要按钮的最小高度为 44px，登录与提交按钮为 48px。
- 保留现有市场选择、登录、绑定、流式对话和本地记录流程。

## 本地验证

在仓库根目录运行：

```sh
node --test miniprogram/tests/ui-behavior.test.js
```

测试覆盖首页统计与记录删除、登录跳转、市场会话初始化、键盘状态处理、生成时的菜单保护和消息复制。

使用微信开发者工具导入本目录，使用现有 `project.config.json`。接口地址由 `utils/config.js` 配置，调试登录与研究对话前需确保对应后端可访问。

浏览器对 WXML/WXSS 的映射预览只用于检查样式，不代表微信原生编译或真机验证。交付前还需在微信开发者工具及 iOS、Android 真机检查：

- 320、375、430px 等屏宽下的长标题、空记录和多条对话。
- 原生导航、胶囊按钮、全面屏底部安全区和横竖屏切换。
- 键盘弹出、收起、多行输入、发送后滚动，以及流式回复期间的操作。
- 微信登录、手机号绑定、验证码倒计时和后端错误提示。
