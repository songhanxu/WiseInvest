# 三端浅色与深色外观

iOS、Web、小程序采用同一组中性色与系统蓝：浅色背景 `#F2F2F7`、内容块 `#FFFFFF`；深色背景 `#000000`、内容块 `#1C1C1E`。主要操作分别使用 `#007AFF` / `#0A84FF`，正文、次要文字、分隔线和输入背景随外观变化。

## 切换入口

- iOS：登录页右上角，或「我的」中的深色模式开关；使用现有 `appearance` 偏好保存。
- Web：右上角和登录页的太阳/月亮按钮，使用 `wiseinvest.theme` 保存。
- 小程序：首页右上角和登录页的「深色 / 浅色」，使用 `appearance` 保存。页面载入、返回时应用外观，切换会同步已打开页面和原生导航栏。

三端采用大标题、白色或深灰分组、统一留白，减少宣传文案、独立边框和装饰色。手机 Web 市场入口与小程序、iOS 的列表结构对齐；Web 桌面继续利用双列展示行情。

## 实现位置

- iOS：`Core/Extensions/Color+Extensions.swift` 与颜色资源；动态颜色跟随 SwiftUI 当前外观。
- Web：`unified-theme.css` 定义最终两套颜色，原有样式中的固定颜色改为主题变量。
- 小程序：`app.wxss` 定义颜色变量，`utils/theme.js` 在每个页面应用外观；富文本和自定义组件继承主题变量。

验证包括 Web 构建与现有测试、小程序 WXML/WXSS 编译及外观保存/页面返回测试、iOS 模拟器构建。Web 另检查两种外观的手机首页和 320px 宽度；这些检查不替代 iOS 与微信真机的逐页视觉验收。
