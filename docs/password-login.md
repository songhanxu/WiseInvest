# Web 账号密码登录

网页在“设置 → 账户”使用账号密码登录或注册。账号为 3–32 位字母、数字、下划线、点或短横线，大小写不区分；密码至少 6 位，最多 72 字节。注册成功后自动登录，不要求手机号或邮箱。密码只传给后端，数据库仅存 bcrypt 哈希；浏览器保留登录会话，不保存密码。

## 现有账户原地升级

当前部署已确认的账户 ID 为 `2`。在服务器 `backend/.env.production` 中增加：

```dotenv
AUTH_BOOTSTRAP_USER_ID=2
AUTH_BOOTSTRAP_USERNAME=admin
AUTH_BOOTSTRAP_PASSWORD=<指定的初始密码>
```

三个配置必须一起设置。部署最新后端后，启动过程给指定账户设置账号密码，保留用户 ID、自选列表、提醒设置、会话、交易所账户绑定。它不会创建替代账户，也不会覆盖其他账户占用的用户名。

迁移成功后应删除这三项配置，重建后端容器加载配置。重复启动不会重置已设置的密码；如果指定的账户不存在或已经使用其他登录名配置了密码，迁移会报错。

本地开发对应 `backend/.env`；本地环境文件不会自动同步到腾讯云。部署沿用 `bash deploy-update.sh`。线上账号密码请求应通过 HTTPS 传输。

## 接口与隔离

- `POST /api/v1/auth/register`：JSON `{ "username": "...", "password": "..." }`，成功返回 201 和登录会话。
- `POST /api/v1/auth/login`：相同请求体，成功返回 200；错误账号和密码统一返回 401。
- `GET /api/v1/auth/me`：返回当前用户的 ID、账号、资料和是否已设置密码，不返回密码哈希。
- 原先未配置微信时的模拟登录已关闭，不能通过测试登录绕过密码。
- 自选、持仓绑定和提醒沿用用户 ID 隔离；会话读取、删除和发言检查归属。浏览器研究历史按服务地址与用户 ID 存放，旧历史仅迁移给升级时已登录的原账号。

仅将用户名改为 `admin` 不会授予跨用户管理权限。
