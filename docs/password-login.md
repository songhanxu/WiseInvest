# Web 账号密码登录

网页登录页使用一个输入框填写账号名、邮箱或手机号，三者共用同一个密码。账号名为 3–32 位字母、数字、下划线、点或短横线，大小写不区分。注册需选择邮箱或中国大陆手机号，并用 6 位验证码确认联系方式；密码为 10–72 字节。已绑定的邮箱或手机号也能用验证码登录。浏览器保留登录会话，不保存密码；正式环境必须使用 HTTPS。

## 现有账户原地升级

仅当现有账户还没有密码时，先确认该账户的用户 ID，再在服务器 `backend/.env.production` 中增加：

```dotenv
AUTH_BOOTSTRAP_USER_ID=<现有账户的用户 ID>
AUTH_BOOTSTRAP_USERNAME=admin
AUTH_BOOTSTRAP_PASSWORD=<指定的初始密码>
```

三个配置必须一起设置。部署最新后端后，启动过程给指定账户设置账号密码，保留用户 ID、自选列表、提醒设置、会话、交易所账户绑定。它不会创建替代账户，也不会覆盖其他账户占用的用户名。

迁移成功后应删除这三项配置，重建后端容器加载配置。重复启动不会重置已设置的密码；如果指定的账户不存在或已经使用其他登录名配置了密码，迁移会报错。

如果现有测试账户已经有账号名和密码，无需配置这三项。本地环境文件不会自动同步到腾讯云。部署沿用 `bash deploy-update.sh`。

## 接口与隔离

- `POST /api/v1/auth/register`：JSON `{ "username": "...", "email": "...", "code": "123456", "password": "..." }`；也可用 `phone` 替代 `email`。成功返回登录会话。
- `POST /api/v1/auth/login`：JSON `{ "identifier": "账号名或邮箱或手机号", "password": "..." }`，成功返回 200；错误账号和密码统一返回 401。旧客户端的 `username` 字段仍可使用。
- `POST /api/v1/auth/email/send-code`、`/email/login`、`/email/bind`：邮箱验证码发送、登录及已登录绑定。手机使用对应的 `/phone/` 接口。验证码服务未配置时返回 503。
- `GET /api/v1/auth/me`：返回当前用户的 ID、账号、资料和是否已设置密码，不返回密码哈希。
- 原先未配置微信时的模拟登录已关闭，不能通过测试登录绕过密码。
- 自选、持仓绑定和提醒沿用用户 ID 隔离；会话读取、删除和发言检查归属。浏览器研究历史按服务地址与用户 ID 存放，旧历史仅迁移给升级时已登录的原账号。

仅将用户名改为 `admin` 不会授予跨用户管理权限。
