# Web 圆桌与个股深入研究

## 慧投圆桌

在「AI 分析」左侧选择「慧投圆桌」。默认邀请主持人、价值派、趋势派和量化派，也可用角色按钮选择参与者。

问题中的 `@价值派`、`@趋势派`、`@量化派` 优先于按钮选择；`@主持人`、`@all`、`@所有人` 邀请全部角色。后端按角色依次生成回复，Web 分别展示并支持复制。讨论期间可停止；已收到的内容会保留，离开页面会取消当前连接。

圆桌通过 `POST /api/v1/conversations` 创建 `agent_type=group_chat` 的会话，使用 `POST /api/v1/messages/group-chat/stream` 获取流式回复。会话与角色标记沿用 Web 的本地历史记录保存机制；不新增跨设备历史同步。

## 个股深入分析

个股详情页包括：

- 技术概览：根据当前周期的真实 K 线计算 MA5、MA20、收盘价相对 MA20 的偏离和最新成交量相对前 20 根均量的比值。数据不足显示缺失状态，最新 K 线未收盘时成交量比值仍会变化。
- 多周期综合报告：使用现有 `/api/v1/stocks/analysis/enhance` 接口，摘要下方可展开 Markdown 报告，并继续向市场 Agent 追问或把标的带入圆桌。
- 重新获取：再次查询后端，仍遵循后端的缓存策略，不强制清空服务端缓存。

普通股票优先读取 `/api/v1/stocks/analysis/cached`。该缓存查询接口不区分交易产品；Bitget 产品直接走支持 `provider_symbol`、`category` 的综合分析接口，避免混用股票与合约报告。

后端当前将分析类型统一为综合分析，因此 Web 的技术概览是 K 线计算结果，没有把同一份 AI 报告伪装成多次独立分析。

## 资讯详情与解读

点击个股资讯可在站内打开摘要与 AI 解读；解读调用 `/api/v1/stocks/news/enhance`。保留查看原文、重新获取和继续追问入口。关闭详情会取消未完成的前端请求；上游无有效结果时显示缺失或错误状态。
