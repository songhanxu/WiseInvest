# 慧投跨端设计语言与昼夜主题

2026-10-17 确认。本文记录后续设计与实现的基准，三端的主题切换尚未完成。

## 已确认的方向

Web、iOS、微信小程序采用统一的设计语言，并支持白天与夜间两套配色。

- 白天模式：以当前小程序和 Web 的浅色风格为基准，使用灰白背景、白色内容块、深色文字与低饱和墨绿色。
- 夜间模式：以当前 iOS 的配色为基准，使用深蓝背景、较浅的深蓝内容块、浅色文字与蓝色强调色。
- 同一个页面在两种主题下保持相同的信息层级、布局、字体层级、组件形态及操作逻辑。
- 各端保留适合平台的原生导航、手势和安全区适配。

## 组件规则

- 统一标题、正文、辅助信息与数值的层级，避免通过过多颜色和装饰争夺注意力。
- 卡片保持简洁的圆角、边界与间距；夜间主题沿用统一的组件形态。
- 按钮、输入框、搜索浮层、表格和对话气泡均需要对应的昼夜状态。
- 涨跌、错误、成功、警告等颜色保留原有业务含义，切换主题时调整明度与对比度。
- 样式使用页面背景、内容背景、主文字、次文字、强调色、分隔线等语义令牌，避免用 `blue` 一类具体色名代表跨主题用途。
